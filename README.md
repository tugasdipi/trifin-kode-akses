# TRIFIN — GitHub Pages Package

Isi folder:
- `index.html` — portal utama
- `pos1.html` s.d. `pos8.html` — halaman akses tiap pos

## Publish ke GitHub Pages
1. Buat repository baru, misalnya `trifin-kode-akses`.
2. Upload seluruh isi folder ini ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch **main** dan folder **/(root)**, lalu **Save**.
6. URL utama akan berbentuk `https://USERNAME.github.io/trifin-kode-akses/`.

URL tiap pos:
- `.../pos1.html`
- `.../pos2.html`
- dst. sampai `.../pos8.html`

Untuk QR, gunakan URL pos yang sesuai. Jangan mengubah nama file bila QR sudah dicetak.
